# 需要下载的文件和文件夹：

📁 src/                    # 整个 src 文件夹
📁 src/app/               # 应用代码
📁 src/styles/            # 样式文件
📁 src/imports/           # 图片资源

📄 package.json           # 依赖配置
📄 vite.config.ts         # Vite 配置
📄 tsconfig.json          # TypeScript 配置（如果有）

# 在本地电脑上需要运行的命令：
1. pnpm install           # 安装依赖
2. pnpm run dev           # 本地运行
